# Trustfolio UI Polish Checklist

Use this checklist when modifying src/ui/Index.html and src/ui/styles.html.

- Typography hierarchy: clear H1/H2/H3 sizing and spacing.
- Forms: consistent input height, focus ring, and disabled states.
- Lists: spacing between rows, muted secondary text, no visual clutter.
- Panels: consistent padding, border, and shadow across sections.
- Status: success/error colors readable on dark background.
- Buttons: primary/ghost contrast, hover/active states visible.
- Layout: grid collapses cleanly on narrow widths.
- Motion: only subtle transitions or staggered reveal if helpful.
